❓ 如果出现错误
================================================================================

1. ModuleNotFoundError: No module named 'psycopg2'
   → 运行：pip install psycopg2-binary

2. OperationalError: could not connect to server
   → 检查网络连接和密码是否正确

3. FileNotFoundError: instance/database.db
   → 确保在项目根目录运行脚本
